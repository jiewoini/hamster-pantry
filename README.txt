猫爪收纳局 / 微信小游戏试玩原型

定位
云养猫和轻度收纳消除。从猫窝进入收纳关卡，通关可获得猫粮、清水、纸箱和小领巾。
首次进入时可从图鉴选择猫咪外观并起名，金渐层在第一页。回到猫窝后可在猫咪档案里更改。
猫粮和清水提高满意度，纸箱提高活跃度，小领巾可穿戴。猫窝状态及收纳进度保存在本机。
新猫窝自带猫粮和清水，轻点小猫也能互动。收纳第一关清空两条，第二至五关清空四、五、六、七条。后续目标在六至八条之间变化。
从猫窝的小游戏入口可以玩零食柜、逗猫棒或猫窝找找找。轻轻拖动羽毛，等小猫扑过来，再让它抓稳。评分达到 80 分即可带回奖励。猫窝找找找是寻物玩法：在房间里找出小零食、帽子和交通玩具，装满六箱即可带回物资。满箱后补发新箱，暂不匹配的物品先放托盘。
纸箱和软垫都能被猫使用。等猫在里面或上面睡着，可以各拍一张纪念照，保存在猫窝相册。
猫窝按设备时间轮换晴、阴、雨三种虚拟天气。逗猫棒可带回窗边软垫、毛线球、鼠尾草绿毛线、布老鼠和响纸袋。
每次提供三块零食方块，拖入 7×7 柜子，或先点选再点击目标位置。
填满整行或整列即可清空。方块方向固定，允许撤回最近一步。
三块全部放好后补货。按当前方向无块可放时结束。
普通模式从第四关起，每局可主动晃动柜子一次。点「晃一下」立即结算下落。棋盘无变化时保留次数，撤回可恢复使用次数。
普通关显示清除进度和倒计时，暂停时停表。每局一次救场，堵死时腾出能放一块的位置，超时则续 45 秒。
经典模式随机开局，每日同题按设备本地日期生成相同方块序列。
每日 800 分为设计目标，不代表玩家成绩、排行榜或真实通关率。

浏览器试玩
可直接打开 preview.html，或在当前目录用静态文件服务器访问。
浏览器与小游戏共用收纳引擎和猫窝逻辑。其他小游戏可以用自己的来源标识和递增里程碑调用 CatCare.grant 发放物资。

微信开发者工具
导入当前目录，项目类型为小游戏。project.config.json 使用 touristappid 作为本地原型占位。
若当前工具不支持游客小游戏，请使用你自己注册的小游戏 AppID。
不要替换原有厕所小程序的 AppID 或将此项目上传到原小程序。
真机预览与发布需要有效的小游戏账号及平台要求的审核、主体和相关资质。
本原型未接入支付、广告、用户登录、联网排行及服务器，不代表已经具备上线条件。

验证
node --test tests/engine.test.js

首轮验证建议
请 10 位用户各玩 3 局，观察能否理解放置和重力提示、失败后是否主动再玩。
记录反馈后再调节方块分布与难度。先不加广告，先验证重玩意愿。
没有自动埋点；个人最佳只保存在本设备，清除缓存后可能丢失。
当前没有中途存档，退出或重新载入会重置当前对局。
